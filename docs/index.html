🤖 技术亮点

  • 产品方法：围绕“职业定位—岗位理解—简历优化—面试准备”构建闭环。
  • AI 接入：前端请求 /api/ai，服务端读取环境变量调用模型，不在前端暴露密钥。
  • 可部署：GitHub Pages 可展示静态作品，Vercel 配置 API Key 后可启用真实 AI。
  • 可讲解：面试时可说明需求拆解、MVP 取舍、接口封装、上线部署与后续迭代。
